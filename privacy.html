プライバシーポリシー

最終更新日: 2026年9月20日

本ポリシーは、大谷 萌梨（以下「運営者」）が運営する YouTube チャンネル「耳で学ぶ 宅建・行政書士・FP合格ナビ」（https://www.youtube.com/@mimigaku-navi）および、運営者が動画の投稿に使用する内製ツール「mimigaku-navi（学習動画の投稿ツール）」（以下「本ツール」）における情報の取り扱いを定めるものです。

1. 本ツールの概要と YouTube API サービスの利用

本ツールは YouTube API サービス（YouTube Data API v3）を利用しています。本ツールを利用することにより、利用者は YouTube 利用規約 および Google プライバシーポリシー に同意したものとみなされます。

本ツールは運営者本人のみが使用し、運営者自身の YouTube アカウント（チャンネル）に対してのみ動作します。一般のユーザーが本ツールを利用することはありません。

2. 取得する情報

本ツールは、Google の OAuth 2.0 認証を通じて、運営者自身のチャンネルに関する次の情報にアクセスします。

  • 運営者がアップロードした動画の ID、タイトル、説明文、公開設定（非公開・限定公開・公開）、予約公開日時、再生リストの情報
  • 運営者が自作した字幕トラックの情報

本ツールは、視聴者や第三者の個人情報（氏名、メールアドレス、コメント、視聴履歴など）を取得しません。また、他のチャンネルのデータを取得しません。

3. 情報の利用目的

  • 自作の学習動画を運営者のチャンネルへアップロードし、公開日時を予約するため
  • 自作の字幕をアップロードするため
  • アップロード済み動画の公開状態を確認し、運営者の手元の台帳と突き合わせるため

4. 情報の保存と共有

取得した情報（動画 ID・公開状態・予約日時など）は、運営者のコンピュータ内のファイルにのみ保存します。外部のサーバーには送信せず、第三者に提供・販売・共有することはありません。認証トークンは運営者のコンピュータ内に保管し、運営者以外がアクセスすることはありません。

保存した情報は、運営者が不要と判断した時点で削除します。

5. Cookie 等について

本サイトおよび本ツールは、Cookie や広告識別子を利用した追跡を行いません。

6. アクセス権の取り消し

本ツールに付与した YouTube アカウントへのアクセス権は、Google アカウントのセキュリティ設定ページ（https://security.google.com/settings/security/permissions）からいつでも取り消すことができます。

7. ポリシーの変更

本ポリシーを変更する場合は、本ページで公開します。
