このサイトについて

「耳で学ぶ 宅建・行政書士・FP合格ナビ」は、行政書士・宅建士・FPなどの資格試験の受験者向けに、過去問の一問一答・判例解説・記述式の学習動画をYouTubeで公開しているチャンネルです。

▶ YouTube チャンネルを見る

mimigaku-navi（学習動画の投稿ツール）

mimigaku-navi は、チャンネル運営者が自作の学習動画をこのチャンネルへ予約投稿し、自作の字幕を付けるために使っている内製ツールです。YouTube API サービス（YouTube Data API v3）を利用しています。運営者本人だけが使用し、一般には配布していません。第三者の YouTube データは取得・保存・表示しません。

mimigaku-navi is an internal tool used by the channel owner to schedule uploads of self-made study videos to this channel and to attach self-authored captions. It uses YouTube API Services. It is used only by the owner and is not distributed. It does not collect, store or display any third-party YouTube data.
